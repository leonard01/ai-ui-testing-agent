# Task list acceptance criteria

- A new task list starts empty and displays `0 tasks, 0 completed`.
- Entering `Prepare interview` in the field labelled `Task` and clicking `Add` creates a visible task.
- Checking `Complete Prepare interview` updates the status to `1 task, 1 completed`.
- Clicking `Delete Prepare interview` removes the task and returns the status to `0 tasks, 0 completed`.

Design one end-to-end UI test covering this lifecycle. Preserve stated expected values even if the application behaves incorrectly.
