### V03-LR02 — distinct Delete targets (negative)
Instructions:
```
Add a task called Review report.
Add a task called Prepare presentation.
Verify that both tasks are visible.
Delete Review report.
Verify that Review report is no longer visible.

Verify that Prepare presentation is no longer visible.
```
Change both Delete click targets to label "Delete". Approve and run. Choose the correct first Delete button. Inspect preview and use single-step repair. First deletion targets Review report only; the second action must not silently inherit the first target. Distinct functional intents can share identical incorrect locators; if bulk scope offers an unsafe shared target, record as design defect for release, not a pass. Verify assertions still distinguish both tasks.
